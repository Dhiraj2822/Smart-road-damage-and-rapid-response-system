# Citizen User Manual - Road Damage Reporter

## Getting Started

### 1. Registration
1. Open the app at http://localhost:5173
2. Click **Register**
3. Fill in your details:
   - Full Name
   - Email Address
   - Phone Number (10 digits)
   - Password
4. Click **Register**
5. You'll be automatically logged in

### 2. Logging In
1. Enter your email and password
2. Click **Login**
3. You'll see the home dashboard

## Reporting Road Damage

### Step-by-Step Guide

1. **Click Report New Issue** from home screen

2. **Fill in Details:**
   - **Title**: Brief description (e.g., "Large pothole on MG Road")
   - **Description**: Detailed explanation of the damage
   - **Ward**: Your ward number (e.g., "Ward 12")
   - **Road Type**: Select from:
     - Highway
     - Main Road
     - Residential
     - Internal

3. **Capture Location:**
   - Click **Capture Location** button
   - Allow browser to access your location
   - Wait for GPS coordinates to be captured
   - Address will be auto-filled

4. **Add Photos:**
   - Click **Add Photos** button
   - Take photos using camera OR select from gallery
   - You can add up to 5 photos
   - Click X to remove any photo

5. **Submit:**
   - Review all information
   - Click **Submit Complaint**
   - You'll receive a confirmation with complaint number

## Tracking Your Complaints

### View All Complaints
1. Click **My Complaints** from menu
2. See list of all your submissions
3. Each card shows:
   - Complaint title
   - Status (color-coded)
   - Severity level
   - Submission date
   - Complaint number

### View Complaint Details
1. Click **View Details** on any complaint
2. See complete information:
   - All photos
   - Location on map
   - Current status
   - Progress timeline
   - Department assigned
   - History of updates

## Understanding Status

| Status | Meaning |
|--------|---------|
| **SUBMITTED** | Your complaint has been received |
| **VERIFIED** | Officials have verified the damage |
| **ASSIGNED** | Assigned to department/contractor |
| **IN_PROGRESS** | Repair work has started |
| **RESOLVED** | Issue has been fixed |
| **REJECTED** | Complaint was rejected (reason provided) |

## Notifications

You'll receive updates via:
- **SMS** - Important status changes
- **Email** - Detailed updates
- **In-App** - Real-time notifications

## Tips for Better Reports

 **DO:**
- Take clear, well-lit photos
- Include multiple angles
- Capture the full extent of damage
- Provide accurate location
- Write detailed description

 **DON'T:**
- Submit duplicate complaints
- Use offensive language
- Submit false reports
- Include personal information in photos

## Troubleshooting

**Can't capture location?**
- Enable location services in browser
- Allow permission when prompted
- Try refreshing the page

**Photos not uploading?**
- Check file size (max 10MB per photo)
- Ensure stable internet connection
- Try different photos

**Forgot password?**
- Click "Forgot Password" on login page
- Enter your email
- Follow reset instructions
